# Postal+

Plugin GLPI 11 para rastreio de envios dos Correios (API Rastro / CWS), com painel,
regras de alerta e notificações (tela, e-mail, WhatsApp via n8n, chamado).

- Pasta do plugin: `postalplus`
- Namespace: `GlpiPlugin\Postalplus` (autoload em `src/`)
- Requisitos: GLPI 11.0.x, PHP 8.2+

Desenvolvido pela Teckcomp.
